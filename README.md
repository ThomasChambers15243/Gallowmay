# Gallowmay

The website and the downloads for Gallowmay, a local, offline reference manager for Windows and macOS.

- **Website and downloads:** https://thomaschambers15243.github.io/Gallowmay/
- **What's new:** https://thomaschambers15243.github.io/Gallowmay/whats-new.html
- **Every version:** the [Releases](https://github.com/ThomasChambers15243/Gallowmay/releases) page

The app's source code is not published. This repository holds only the website, which is written afresh at each release. Questions and problems are welcome as [issues](https://github.com/ThomasChambers15243/Gallowmay/issues).
